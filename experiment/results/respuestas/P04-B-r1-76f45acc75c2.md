Los seis componentes de un escenario de calidad son (raw/3-1-atributos-de-calidad-2.md, diap. 6):

1. **Fuente**: persona o sistema que inicia el estímulo.
2. **Estímulo**: evento que requiere que el sistema responda.
3. **Artefacto**: parte del sistema o el sistema completo.
4. **Entorno**: circunstancias operativas; siempre debe definirse, incluso si es "normal".
5. **Respuesta**: acción visible externamente.
6. **Medida de respuesta**: criterio de éxito del escenario; debe ser específico y medible.
