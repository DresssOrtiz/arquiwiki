# Clase 1: Fundamentos de arquitectura de software (MUESTRA)

> Documento sintético de muestra para probar los pipelines. Se reemplaza por los apuntes reales del curso.

## Qué es la arquitectura de software

La arquitectura de software es el conjunto de estructuras necesarias para razonar sobre un sistema: sus elementos, las relaciones entre ellos y las propiedades de ambos. Se decide temprano y es costosa de cambiar después.

## Para qué sirve

- Comunicar el diseño entre los interesados.
- Tomar decisiones tempranas que condicionan los atributos de calidad.
- Servir de base para estimar costo y riesgo.

## Vistas y estilos

Una sola vista no basta. Se documentan varias vistas (de módulos, de componentes y conectores, de asignación) y se reconocen estilos comunes como capas, microservicios, pipes and filters y Blackboard.
