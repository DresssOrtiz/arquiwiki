# Proceso de desarrollo de software

## Resumen
Conjunto de fases y artefactos que va desde una necesidad del usuario hasta el mantenimiento y la deprecación del sistema, con roles que cambian entre enfoque tradicional y ágil.

## Desarrollo
- Ciclo de vida con fases como análisis de requerimientos, diseño de la solución, desarrollo y evaluación, despliegue, y mantenimiento y evolución (raw/1-2-definiciones-1.md, diap. 4).
- Fase de descubrimiento y abstracción: una necesidad del usuario dispara el análisis de requerimientos, la comprensión del problema, el análisis y documentación, el modelado y el diseño de la solución (raw/1-2-definiciones-1.md, diap. 8).
- Fase de construcción: solución detallada, programación e integración, automatización de pruebas, y despliegue a infraestructura y operaciones, hasta obtener un artefacto de software (raw/1-2-definiciones-1.md, diap. 9).
- Fase de operación: con el software disponible se hace mantenimiento y evolución (arreglo de errores, nuevas funcionalidades) hasta que el sistema se depreca (raw/1-2-definiciones-1.md, diap. 10).
- Roles tradicional → ágil (raw/1-2-definiciones-1.md, diap. 17):
  - Experto del dominio → partes interesadas (stakeholders).
  - Analista → cliente / dueño del producto.
  - Administrador de sistemas (SysAdmin) → DevOps / SRE (site reliability engineer).
  - Arquitecto, desarrollador, QA–tester → equipo de desarrollo (team).
  - Gestor del proyecto → facilitador.
