# Ingeniería de software

## Resumen
Disciplina propuesta en 1968 para responder a la "crisis del software". Es el proceso metodológico para construir soluciones de software.

## Desarrollo
- El concepto se propuso originalmente en 1968, en una conferencia para discutir la "crisis del software" (raw/1-2-definiciones-1.md, diap. 3).
- Se volvió claro que los enfoques individuales de desarrollo no escalaban a sistemas grandes y complejos, que eran poco confiables, costaban más de lo esperado y se entregaban con demora (raw/1-2-definiciones-1.md, diap. 3).
- En las décadas de 1970 y 1980 surgieron técnicas como la programación estructurada, el encubrimiento de información y el desarrollo orientado a objetos; se perfeccionaron herramientas y notaciones estándar (raw/1-2-definiciones-1.md, diap. 3).
- Es el proceso metodológico para la construcción de soluciones de software, con varios paradigmas: modelo de cascada, modelo de espiral, desarrollo iterativo e incremental y desarrollo ágil (raw/1-2-definiciones-1.md, diap. 4).
