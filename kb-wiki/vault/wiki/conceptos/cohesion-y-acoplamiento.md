# Cohesión y acoplamiento

## Resumen
Dos medidas de la relación entre unidades de software: el acoplamiento es su interdependencia y la cohesión es qué tan unidos están sus elementos para lograr un mejor resultado.

## Desarrollo
- **Acoplamiento:** grado de interdependencia entre dos unidades de software (clases, subtipos, métodos, módulos, funciones, bibliotecas, etc.). Si son completamente independientes, están desacopladas (raw/1-2-definiciones-1.md, diap. 45).
- **Cohesión:** grado en que elementos diferentes de un sistema permanecen unidos para alcanzar un mejor resultado que si trabajaran por separado; es la forma de agrupar unidades de software para crear una unidad mayor (raw/1-2-definiciones-1.md, diap. 45).
