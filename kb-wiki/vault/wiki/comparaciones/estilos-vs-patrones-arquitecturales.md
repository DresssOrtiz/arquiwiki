# Estilos vs patrones arquitecturales

## Resumen
Un patrón es una solución prediseñada a un problema; un estilo es un modelo conceptual que define un vocabulario común. Algunas decisiones pueden actuar como ambos.

## Desarrollo
| Aspecto | Patrón | Estilo |
|---|---|---|
| Naturaleza | Solución prediseñada para un problema (raw/2-1-definiciones-2.md, diap. 8) | Modelo conceptual que define un vocabulario común (raw/2-1-definiciones-2.md, diap. 8) |
| Aplicación | En cualquier contexto donde se presente el problema (raw/2-1-definiciones-2.md, diap. 8) | Restringe decisiones en un contexto determinado (raw/2-1-definiciones-2.md, diap. 6) |

- Algunas decisiones de diseño arquitectural pueden actuar al mismo tiempo como estilos y patrones (raw/2-1-definiciones-2.md, diap. 8).
