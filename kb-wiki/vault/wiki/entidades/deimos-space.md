# Caso de estudio DEIMOS Space

## Resumen
DEIMOS Space tiene como objetivo liderar el desarrollo de software empotrado en tiempo real, cubriendo el ciclo de vida desde el análisis de requisitos hasta la validación y aceptación (raw/3-2-atributos-de-calidad-3.md, diap. 28).

## Desarrollo
- Usa típicamente HOORA/UML para análisis y modelado de requisitos, y HRT-HOOD y Ada/C/C++ para diseño e implementación (raw/3-2-atributos-de-calidad-3.md, diap. 28).
- Software de control de vuelo crítico en seguridad (AOCS, ACMS, GNC), con técnicas de aseguramiento como análisis RAMS (fiabilidad, disponibilidad, mantenibilidad y seguridad), FTA, FMECA y SEEA (raw/3-2-atributos-de-calidad-3.md, diap. 28).
- Otras áreas: software de tratamiento de datos a bordo (OBDH), software de control de instrumentos, validación de software del segmento espacio y simulación de sistemas embarcados (raw/3-2-atributos-de-calidad-3.md, diap. 29).
- Taller: identificar atributos de calidad, escenarios y acuerdos para cada caso de estudio (raw/3-2-atributos-de-calidad-3.md, diap. 32).
