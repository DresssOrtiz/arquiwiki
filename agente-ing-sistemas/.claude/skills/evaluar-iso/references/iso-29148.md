# ISO/IEC/IEEE 29148 (ingeniería de requisitos), resumen propio

> Resumen con palabras propias, hecho para orientar. La norma tiene derechos de autor: cotejar con el texto oficial.

La norma trata el proceso de requisitos y fija atributos de calidad para un requisito individual y para el conjunto.

## Características de un requisito bien formado
| Característica | Prueba rápida | Defecto típico |
|---|---|---|
| Necesario | Si se quita, ¿falta algo que el interesado requiere? | requisito decorativo o heredado sin dueño |
| Apropiado | ¿Está en el nivel correcto (negocio, sistema, componente) y no dicta diseño? | impone tecnología sin razón |
| Inequívoco | ¿Admite una sola lectura? | "fácil", "rápido", "etc.", "y/o" |
| Completo | ¿Se entiende solo, con actor, condición, acción y medida? | falta el actor o la condición |
| Singular | ¿Expresa una sola cosa? | varios "y" encadenando comportamientos |
| Factible | ¿Se puede lograr con las restricciones conocidas? | cifras irreales, tecnología inexistente |
| Verificable | ¿Se puede demostrar con prueba, inspección, análisis o demostración? | sin criterio medible |
| Correcto | ¿Refleja la necesidad real del interesado? | contradice la fuente |
| Conforme | ¿Sigue la plantilla y el estilo acordado? | sin identificador, sin "debe" |

## Características del conjunto de requisitos
| Característica | Pregunta |
|---|---|
| Completo | ¿Cubre todo el alcance sin huecos? |
| Consistente | ¿No hay contradicciones ni duplicados? |
| Factible | ¿El conjunto cabe en presupuesto, plazo y tecnología? |
| Comprensible | ¿Terminología uniforme y estructura clara? |
| Validable | ¿Se puede confirmar con los interesados que es lo que quieren? |

## Plantilla útil
"[Condición] [Actor] debe [acción] [objeto] [medida o restricción]."
Ejemplo: "Cuando un usuario autenticado envíe una búsqueda, el sistema debe devolver resultados con p95 menor a 2 s con 60 usuarios concurrentes."

## Veredictos
- **Cumple**: la prueba rápida se supera y hay evidencia citada.
- **Parcial**: se supera en parte (p. ej., hay medida pero falta condición).
- **No cumple**: la prueba falla; proponer reescritura.

## Atributos de apoyo recomendados
Identificador único, prioridad, fuente, estado, método de verificación, trazabilidad a diseño y pruebas.
